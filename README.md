# Tides of Survival

A Warcraft II survivors-like fan game that runs in your browser.

**Play:** https://jonathansadowitz.github.io/tides-of-survival-play/

This repository holds only the game's code. It contains no Blizzard graphics, sounds or music: the game reads those at runtime from your own copy of **Warcraft II: Battle.net Edition** (for example the GOG release). Open the page, choose **Asset Lab**, then **Import game folder**, and pick your `Warcraft II BNE` folder or any folder above it.

After the first visit the game also works offline.
